# Carom

Carom is a fast, top-down paddle duel. Bend rallies with paddle spin, bank shots around the central bumpers, and outplay either the AI or a friend on one keyboard.

Install dependencies with `npm ci`, then run `npm run dev` for a local development server. Build the self-contained static site with `npm run build`; it writes the deployable site to `dist/`.

Controls: Player one uses **W/S**. Player two uses **Up/Down** in Versus, while either pair controls Player one in Solo. **Enter** or **Space** confirms menus, **P** pauses, and **M** mutes.
